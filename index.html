실구멍을 봉쇄하세요

적을 처치해 화면의 목표를 채우세요. 목표를 달성하면 새 실구멍은 더 이상 나타나지 않고, 이미 열린 구멍은 저절로 닫힙니다. 열린 구멍이 모두 닫히고 적이 남지 않으면 다음 스테이지로 넘어갑니다.

같은 등급의 적은 합쳐지고, 2등급 이상은 죽으면 둘로 갈라집니다.

이동과 회피

  • 이동: A·D / 방향키 / 화면 패드
  • 점프: W·Space / ↑ 버튼
  • 발판 내려가기: S·↓ 유지 / 패드 아래
  • 대시: Shift / 대시 버튼

바늘과 적의 돌진

  • 클릭·터치로 바늘 발사, 유지하면 연사
  • 적의 주황색 충전 예고 뒤 대시 접촉은 피해
  • 스탯: T / 스탯 버튼 · 레벨마다 1점
  • 일시정지: P·Esc / Ⅱ · 싱글만 가능

투자는 다음 모험에도 유지

바늘: 피해 → 빠른 연사 → 분열 메아리
제어: 벽·발판 아래 고정 → 3체 튕겨꿰기 → 바늘 재명중 회수절단

기동·생존은 반복 투자할 수 있습니다. 새 모험·재시작·새로고침에도 투자는 보존됩니다.
