털실 대소동

합치고 갈라지는 털실 적을 베고,
실구멍을 모두 봉쇄하세요.

방을 만들거나 코드를 입력해 참가하세요.

목표

적을 처치하면 실구멍이 하나씩 막힙니다. 모든 구멍을 막고 남은 적까지 처치하면 다음 스테이지로 이동합니다.

같은 등급의 적은 합쳐지고, 2등급 이상은 죽으면 둘로 갈라집니다.

조작

  • 이동: A·D / 방향키 / 화면 패드
  • 점프: W·Space / ↑ 버튼
  • 발판 내려가기: S·↓ 유지 / 패드 아래
  • 대시: Shift / 대시 버튼
  • 공격: 클릭 3연격 · 길게 눌러 바늘 발사
  • 스탯: T / 스탯 버튼 · 레벨마다 1점
  • 일시정지: P·Esc / Ⅱ · 싱글만 가능

성장

검술은 전진 → 띄우기 → 분열 잔격, 제어는 벽 고정 → 관통 → 회수절단으로 이어집니다. 기동과 생존은 반복 투자할 수 있습니다. 새 모험을 시작하면 투자는 초기화됩니다.
