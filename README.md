# 털실 대소동 / Yarn Mayhem

같은 등급의 털실 적이 합쳐지고 다시 분열하는 횡스크롤 액션 RPG. 바늘 원거리 공격으로 실구멍을 봉쇄하고, 스탯 트리를 키워 혼자 또는 최대 4명이 함께 도전합니다.

**[바로 플레이 / Play](https://byh-playground.github.io/yarn-mayhem/)** · **v0.14.0**

![실제 Edge에서 실행한 2인 플레이](docs/gameplay.png)

Merge-and-split yarn enemies, primary ranged needles and shared charged-dash enemies in a physics action RPG for 1–4 players.


## 0.14.0 바늘 기본공격과 적 충전대시

- 적의 접근 공격은 플레이어와 같은 충전 수(2), 재충전(830ms), 속도(830px/s), 지속시간(190ms), 벽 제한과 수직 속도 보존을 가진 동일 대시 함수로 실행합니다. 적의 컨트롤러만 450ms 충전 예고 → 190ms 대시 접근 → 150ms 공격 → 500ms 회복을 공급합니다. 기존 합체 우선 행동과 티어별 크기·체력·보상은 유지합니다.
- 충전 중 선택한 생존 목표를 추적하고 주황색 원·방향 선으로 알립니다. 발사 시 방향이 잠깁니다. 접촉 피해는 접근 뒤 별도 공격 단계에만 있으며, 예고·대시 접근·회복·단순 접촉으로 피해를 주지 않습니다. 데미지는 8 + 티어 × 2입니다. 회복 뒤 500ms 공격 대기가 있습니다.
- T1~T5는 접근 공격을 사용합니다. T6~T8은 같은 대시에 기존 바늘 투사체 1발을 추가하고, T9~T10은 3발 부채꼴을 추가합니다. 속도 480px/s, 피해 8 + 티어이며 450ms 예고와 대시 접근 뒤 공격 단계에서 발사됩니다. 이 최초 원거리 티어와 수치는 이번 후보의 튜닝 제안값입니다.
- 밀어꿰기·튕겨꿰기·회수절단을 유지합니다. 회수절단은 고정 적에 기본 바늘 재명중으로 이어집니다. 바늘 앞끝·몸통 가림·뒤쪽 끝과 인접 지형 절단은 기존 렌더러를 사용합니다.
- 솔로와 호스트는 동일 stepWorld를 실행하고 게스트는 확정 스냅샷을 표시합니다. 적의 공격 예고 상태가 스냅샷에 포함되므로 room 계약은 v0140입니다. 기존 진행 저장은 보존되며 함께 플레이하는 모든 창을 새로고침해야 합니다.
- 고정 변경 흐름 검증: npm run test:combat. 일반 저장·투자·합체·실제 RTC 회귀: npm test. 상세 결과는 [검증 기록](docs/verification.md)에 남깁니다.

## 조작

- A/D·방향키 이동, W/Space 점프, S/↓ 유지로 발판 내려가기, Shift 대시.
- PC 클릭과 모바일 바늘 버튼은 즉시 바늘을 발사하고, 유지하면 연사합니다. T/스탯 버튼은 기술 트리입니다. 검술을 구매했다면 E 또는 별도 검술 버튼으로 3콤보를 사용합니다. 기본 공격 버튼에서 검술은 발동하지 않습니다.
- 모바일은 이동 패드와 점프·대시·공격 버튼을 사용합니다.
- 시작 → 싱글 플레이로 바로 시작하거나, 시작 → 멀티 플레이에서 방을 만들고 4자리 코드를 공유합니다. 방장이 물리와 판정을 실행하고 참가자는 입력을 보내며 확정 상태를 받습니다. 30TPS입니다.

## 메뉴와 스탯 트리

- 메인은 시작·스탯 트리·플레이 방법만 표시합니다. 뒤로 / Esc로 한 단계 돌아가며, 모드 선택만으로 새 게임이 시작되지 않습니다.
- 검술·제어·기동·생존 버튼으로 계열을 바로 바꿉니다. 노드는 잠겨 있어도 선택해 효과와 선행 조건을 확인할 수 있으며, 별도의 **투자하기** 버튼으로 포인트를 사용합니다.
- 화살표는 선행 관계, 금색 선택 테두리는 현재 조회, 문구는 잠김·포인트 부족·투자 가능·완료를 표시합니다. 트리 상단의 포인트·닫기와 상세 하단의 투자 버튼은 별도 영역입니다.
- `#/start`, `#/multiplayer`, `#/help`, `#/tech/bladeEcho`로 메뉴/선택을 복원합니다. URL 진입은 구매나 게임 시작을 실행하지 않습니다.

## 검술 · 제어 트리

각 노드는 1점으로 한 번 해금합니다. 다음 노드는 바로 앞 노드를 요구합니다. 기동·생존 트리는 기존 효과를 유지합니다.

- 검술: **이어베기**는 1·2타 적중 시 최대 20px의 짧은 전진과 약한 밀침으로 연격 거리를 유지합니다. **올려베기**는 3타 생존자를 띄웁니다. 자동 점프는 없으며 직접 추격합니다. **풀어베기**는 3타 처치로 실제 분열한 두 조각에 0.3초 뒤 원래 3타 피해의 25% 잔격을 한 번씩 줍니다. 잔격은 다시 잔격을 만들지 않습니다.
- 제어: **밀어꿰기**는 바늘 피해 후 첫 생존 적에게 피격 방향으로 한 번 임펄스를 줍니다. 중력과 마찰을 받으며 날아가고, 3초 안에 실제 벽·바닥·발판 표면을 향한 충돌 직전 속도가 300px/s 이상이면 1.2초 고정합니다. 느린 충돌과 스침은 일반 물리 충돌입니다. 일반 상향 점프는 발판을 통과합니다. 밀어꿰기로 날아가는 적은 발판 아래에 법선 속도 300px/s 이상으로 충돌해도 고정됩니다. **튕겨꿰기**는 그 적의 날아감과 별개로 바늘이 420px 안의 서로 다른 적을 최대 3체까지 실제로 튕깁니다. 접촉할 때만 피해를 주며, 첫 적이 죽었으면 다음 생존 접촉 적이 임펄스를 받습니다. 이동 중 대상이 사라지면 살아 있는 대상이나 합체 후속 개체를 다시 찾고, 아무도 없으면 바늘이 사라집니다. **회수절단**은 고정된 적에 바늘 재명중 시 지형 바깥쪽 법선 방향으로 튕겨 첫 다른 적에게 그 바늘 피해의 50% 충돌 피해를 한 번 줍니다. 바늘에 죽으면 기존 분열이 발생합니다.
- 날아감·고정 중에는 AI 공격·합체가 멈추지만 피해는 계속 받습니다. 재명중으로 지속시간은 늘어나지 않습니다. 해제 뒤 0.8초 동안 재고정을 막습니다. 분열 조각에는 고정이 상속되지 않습니다.
- 튕긴 지점에서 날카롭게 꺾인 잔상, 바늘 끝 섬광, 실 파편과 단계별로 올라가는 타격음, 긴 실 꼬리, 꽂힌 바늘 떨림, 벽 충돌 압축·파편·타격음과 거리 감쇠 흔들림, 해제 후 풀리는 실을 사용합니다. 시각 변형은 물리 몸체를 바꾸지 않습니다. 고정된 바늘은 몹 뒤의 축·바늘귀, 몸에 가려지는 관통 부분, 몹 앞에서 지형 접촉점으로 이어지는 축으로 나누어 그립니다. 고정 시 다른 몸체/지형을 침범하지 않는 범위에서 최대 18px만 띄워 앞축을 보여 줍니다.

0.13.1은 바늘 고정의 앞뒤 관통 표현과 작은 고정 간격을 보완한 호환 패치입니다. 기존 외곽 충돌 벽도 실제 위치에 그리며 경계에서 카메라가 벽 면을 조금 보여 줍니다. 0.13.0 성장 저장·방·스냅샷 계약은 유지합니다. 실제 PC 시각 검증은 병합 전에 확인하며, 임시 기하/물리 검사는 브라우저 시각 검증으로 표시하지 않습니다.

## 성장 저장과 함께 플레이

- 획득한 스탯 포인트와 투자한 기술은 이 브라우저에 자동 저장합니다. 시작·재시작·새로고침·방 만들기·참가·나가기로 지워지지 않습니다. 새 게임은 스테이지/경험치/전투 상태를 새로 시작하고 체력·대시는 회복합니다. 누적 획득점과 이미 투자한 기술은 유지합니다.
- 저장은 누적 획득점과 기술별 투자 단계만 포함합니다. 남은 점수와 능력치는 기술 정의에서 다시 계산합니다. 체력, 현재 월드와 다른 사람의 성장은 저장하지 않습니다. 브라우저 데이터 삭제·다른 브라우저/기기는 별도이며, 저장이 차단되면 스탯 창에서 알립니다.
- 싱글과 멀티 방장은 같은 `stepWorld`와 투자 액션을 사용합니다. 입력만 로컬/RTC에서 수집합니다. 참가자는 입력과 투자 요청을 보내고 호스트의 확정 결과를 표시합니다. 참가 전 자신의 투자는 입장 데이터로 전달하고, 호스트가 기술·최대 단계·선행 조건·포인트 비용을 검증한 뒤 적용합니다. 원격이 보낸 최종 능력치를 그대로 적용하지 않습니다.
- 0.13.0은 누적 성장 입장 데이터와 플레이어 스냅샷 계약을 변경하므로 같은 버전끼리만 접속합니다. 함께 플레이하는 사람 모두 새로고침하세요.

0.13.0은 실제 PC Edge 155에서 투자→시작/재시작/새로고침, 서로 다른 호스트·참가자 투자와 실제 RTC, 방 나가기 후 복원, 대시/체력/바늘 효과를 확인했습니다. 집중 검사 18개와 수정된 임시 브라우저 시나리오 23개가 통과했습니다. 기존 테스트의 누락된 제어 탭 선택을 수정했으며, 수정 전 테스트는 통과로 표시하지 않습니다. 물리 모바일 기기·실제 음질은 미검증입니다. [상세 검증 기록](docs/verification.md)을 참고하세요.

## 실행과 검증

`index.html` 하나가 현행 소스이자 배포 게임입니다. 인터넷 연결이 필요하며 Matter.js와 GameKit을 고정 CDN 주소에서 로드합니다.

```sh
npm run dev
# http://127.0.0.1:8000
npm ci
npm test
```

Windows 테스트는 설치된 Edge를 사용합니다. Linux에서는 `npx playwright install --with-deps chromium` 후 실행합니다. `TEST_URL`로 공개 URL을 검증할 수 있습니다. 실행 상한은 180초이며 외부 Nostr/RTC 장애는 실패로 기록합니다. 산출물은 `test-results/`에 보관합니다.

0.10.1 메뉴/트리는 실제 DOM(jsdom)에서 11개 화면·선택·투자 흐름과 18개 실제 Matter.js 전투 진단을 통과했습니다. 브라우저 화면 크기별 시각·터치·RTC 검증은 환경 차단으로 미검증입니다. 게임·통신 계약은 0.10.0과 같습니다.

0.10.0은 실제 Matter.js 0.20.0으로 전투·벽 고정·해제·분열·스냅샷을 실행한 임시 Node 검사와 정적 빌드를 통과했습니다. DOM·렌더·오디오는 검사 대역이며, 실제 GPU 화면·사운드·RTC·터치 입력은 이번 버전에서 미검증입니다. 기존 브라우저의 소켓/WebGL 차단을 우회하지 않았습니다. 범위는 [검증 기록](docs/verification.md)을 확인하세요.

PR CI는 문법과 배포 산출물을 검사합니다. 실제 RTC 검증은 로컬 E2E이며 CI 성공만으로 대신하지 않습니다. main 병합 뒤 Actions Pages가 동일 HTML과 [빌드 정보](https://byh-playground.github.io/yarn-mayhem/build.json)를 배포합니다.
